Setup carried out

  1. Create a GA4 property named {{ prop.property_name }} under the account of {{ prop.account }}.
  2. Add the web data stream {{ prop.stream }}. Creating it issues the Measurement ID shown above.
  3. Paste the gtag.js snippet into the page head and pass user_id: {{ prop.user_id }} in the config call, so activity is tied to this account.
  4. Leave enhanced measurement on, so views, scrolls and outbound clicks are collected without extra code.
  5. Fire the e-commerce events below, confirm them in Reports > Realtime, and mark purchase as a key event.
