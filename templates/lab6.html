Lab 6 — Google Analytics Setup and Parameters

The GA4 tracking snippet is installed on every page of the store, e-commerce events are fired from the buttons below, and the parameters measured are listed underneath.

Setup steps followed

  1. Created a Google Analytics 4 property for the store in analytics.google.com.
  2. Added a Web data stream for the site URL, which produced the Measurement ID {{ measurement_id }}.
  3. Pasted the gtag.js snippet inside <head> of the shared layout templates/base.html, so all six lab pages are tracked.
  4. Enabled enhanced measurement, so page views, scrolls and outbound clicks are collected without extra code.
  5. Fired the e-commerce events below and confirmed them in Reports > Realtime, then marked purchase as a key event.

The Measurement ID above is a placeholder. Replacing it with the ID of a real GA4 property is the only change needed for live data to flow.

Tracking snippet installed

<script async src="https://www.googletagmanager.com/gtag/js?id={{ measurement_id }}"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', '{{ measurement_id }}');
</script>
